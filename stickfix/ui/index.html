        Reset the controller?

        This restarts the controller in Windows, the same as Disable then Enable in Device Manager. Here's what happens:

        1. Windows asks for permission. Restarting a device needs administrator rights, so a prompt for PnP Utility appears. Click Yes to go ahead, or No to cancel.
        2. The controller disconnects for a few seconds and comes back by itself. A running game loses input for that moment.
        3. HidHide attaches to it again, so Windows menus and games stop seeing the drifting original.
